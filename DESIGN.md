# Flow — Design Experiment · дизайн-система

Ветка `design-experiment`. Слой поверх исходного `flow.css`, бизнес-логика, данные, роли и API не менялись.

## Направление — «Командный центр»
Светлая основная тема. Главный вопрос любого экрана — срок ввода, поэтому на портфеле и обзоре объекта он
показан шкалой: старт → сегодня (сигнальный оранжевый) → директивный срок (синяя метка) → прогноз (точка цвета статуса),
отставание — красная зона между директивным сроком и прогнозом.

## Токены (светлая)
- Поле `--plane #EEF0F5`, поверхность `--surface #FFF`, текст `--ink #0A1226 / --ink-2 #4A5570 / --ink-3 #6B7590`.
- Действие `--brand #2F54EB` (наведение `#2342C9`), сигнал «сегодня» `--signal #FF6A1A`.
- Статусы: `--good #0E9F6E`, `--warn #E08600`, `--crit #E0383E`.
- Боковая панель: `--sb-bg #E7EFFB`, активный пункт — белая плашка с синим текстом; в тёмной теме `#060A17`.
- Радиусы 16 / 12 / 10 / 8; глубина `--elev-1`, `--elev-2`, слои `--float`.

## Типографика
Golos Text (OFL), табличные цифры. h1 28–42 px / 700, показатели 38 px / 700, подписи 12–14 px предложением, без капслока и разрядки.

## Движение (по Emil Kowalski)
`--ease-out cubic-bezier(0.23,1,0.32,1)`, `--ease-in-out cubic-bezier(0.77,0,0.175,1)`, `--ease-drawer cubic-bezier(0.32,0.72,0,1)`.
Нажатие 140 мс `scale(.97)`, окно 220 мс, боковая панель/лист 340 мс, уход быстрее входа, наведение только для мыши.
`prefers-reduced-motion`: без смещений и масштаба, остаётся прозрачность.

## Запреты (Impeccable / Taste)
Без надзаголовков-кикеров, цветных полос слева, градиентного текста, свечений, декоративной штриховки, колец вместо данных.
`impeccable detect` по изменённым файлам — 0 замечаний.
