FLOW — тестовый сайт GitHub Pages

1. Распакуйте архив.
2. Загрузите СОДЕРЖИМОЕ папки в корень ветки main репозитория test-flow-new-design (не папку целиком).
3. Settings → Pages → Deploy from a branch → main → /(root).
4. Откройте https://petrzdes-jpg.github.io/test-flow-new-design/

Внимание: статический сайт использует существующий внешний API FLOW. GitHub Pages не запускает FastAPI/PostgreSQL. Не используйте тестовую копию для изменения реальных данных.
